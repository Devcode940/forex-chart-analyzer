## 2025-05-18 - Vectorizing synthetic data generation and parallelizing cross-validation in MLEnsemble
**Learning:** Generating 2,000 synthetic samples in a Python loop introduced ~500ms latency, and running `cross_val_score` sequentially with 200 estimators per model took over 30s. Vectorizing 2D NumPy array generation reduced synthetic generation from ~500ms to ~8ms. Setting `n_estimators` to optimal size (100 for RF, 80 for GB) and using `n_jobs=-1` on `cross_val_score` with `n_jobs=1` on base estimators reduced total MLEnsemble runtime from ~38.4s to ~5.08s (~87% speedup).
**Action:** When working with scikit-learn models in Streamlit, vectorize all synthetic/training data generation using 2D NumPy matrices and avoid thread oversubscription when parallelizing cross-validation.
