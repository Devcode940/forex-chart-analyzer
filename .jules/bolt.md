## 2026-03-30 - Vectorizing Synthetic Data & Parallel Cross-Validation Overhead
**Learning:** In scikit-learn ensemble pipelines, running `n_jobs=-1` inside individual base models (e.g. `RandomForestClassifier`) while sequentially executing `cross_val_score` causes CPU thread contention and severe latency overhead. Setting `n_jobs=-1` on `cross_val_score` while fixing `n_jobs=1` on base models achieves optimal thread utilization. Additionally, vectorizing synthetic data row loops into 2D NumPy array operations reduces data generation latency from ~500ms to ~8ms.
**Action:** When parallelizing model evaluations or cross-validations, set `n_jobs=-1` on the outer cross-validation call and `n_jobs=1` on inner estimators. Vectorize all sample generation using NumPy 2D array broadcasting and indexing.
