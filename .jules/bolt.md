## 2026-10-16 - Vectorized Synthetic Feature Generation & CV Parallelism in MLEnsemble
**Learning:** Sequential scalar row-by-row loops in `_generate_synthetic_data` (2,000 iterations) and single-threaded cross-validation (`cross_val_score` on 5 folds for 200-estimator RF and 150-estimator GB) caused `MLEnsemble.train_and_predict` to take ~39.9s per call. Vectorizing feature matrix generation with 2D NumPy array operations and setting `n_jobs=-1` on `cross_val_score` (with `n_jobs=1` passed to internal estimator folds to avoid thread oversubscription) reduces execution latency from ~39.9s to ~12.8s (~68% speedup).
**Action:** When creating synthetic datasets for ML models in Python, vectorize row generation into 2D NumPy arrays rather than iterating row-by-row in Python loops, and set `n_jobs=-1` on `cross_val_score` while passing `n_jobs=1` to internal estimators.
