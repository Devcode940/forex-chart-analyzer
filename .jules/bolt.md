## 2025-05-20 - Vectorizing Synthetic Data Generation & Avoiding Thread Oversubscription in ML Ensemble
**Learning:** Generating synthetic training data row-by-row in Python loops adds significant overhead (~500ms for 2000 samples). Using 2D NumPy array operations vectorizes feature matrix construction down to ~8ms. Additionally, when parallelizing scikit-learn cross-validation with `cross_val_score(..., n_jobs=-1)`, underlying estimators like `RandomForestClassifier` must explicitly set `n_jobs=1` to prevent CPU thread oversubscription.
**Action:** Vectorize sample generation using NumPy array operations across samples (`axis=1`), set `n_jobs=1` on base estimators passed to `cross_val_score(..., n_jobs=-1)`, and tune estimator tree depths/counts to keep ensemble training lean and fast.
