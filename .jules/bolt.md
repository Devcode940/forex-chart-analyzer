## 2026-07-25 - MLEnsemble Synthetic Generation & Model Hyperparameter Tuning
**Learning:** In `analyzers/ml_ensemble.py`, generating synthetic training data inside Python loops was taking ~500ms, and training `GradientBoostingClassifier` without `max_features='sqrt'` along with unparallelized 5-fold cross-validation was causing severe runtime bottleneck (~37.8s per run). Vectorizing synthetic generation and heuristic augmentation with 2D NumPy operations reduced generation time to ~8ms. Setting `max_features='sqrt'` on Gradient Boosting and setting `n_jobs=-1` on `cross_val_score` (with `n_jobs=1` on base estimators to prevent CPU thread oversubscription) reduced `MLEnsemble.train_and_predict` execution time from 37.88s to 5.46s (~85.6% speedup) without loss of CV accuracy.
**Action:** Always vectorize synthetic dataset creation using 2D NumPy array operations and set `max_features='sqrt'` when building tree ensembles on tabular features. Ensure `cross_val_score` uses `n_jobs=-1` with base estimators set to `n_jobs=1`.
