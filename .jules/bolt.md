## 2025-02-28 - Vectorize Monte Carlo Simulation and Bootstrap Resampling in Statistical Validator
**Learning:** In statistical validation, running sequential `np.polyfit` inside Python loops for thousands of bootstrap resamples creates massive overhead (~2.67s for 10,000 iterations). By generating a 2D sample matrix and computing $R^2$ using algebraic OLS Pearson covariance across 2D NumPy matrices, execution speed increases by >30x (~0.07s). Similarly, simulating Geometric Brownian Motion price paths via 2D matrix operations (`smoothed[0] * np.cumprod(1 + random_returns, axis=1)`) improves Monte Carlo performance by >11x.
**Action:** Always prefer 2D NumPy array matrix operations over Python iteration loops when computing Monte Carlo or Bootstrap metrics, and compute simple linear regression statistics via OLS algebraic formulas instead of calling `np.polyfit`.
