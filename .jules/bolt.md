## 2025-02-16 - [Vectorized Bootstrap Resampling and algebraic OLS]
**Learning:** Sequential calls to `np.polyfit` inside large loops (e.g., 5,000–10,000 bootstrap resamples) cause extreme performance bottlenecks because of internal validation overhead in `np.polyfit` and Python interpreter overhead. This can be resolved by vectorizing the entire bootstrap resampling process into 2D NumPy operations and using an algebraic Ordinary Least Squares (OLS) formula via `np.einsum` to calculate trend $R^2$ scores in a single, lightning-fast matrix operation.
**Action:** Replace sequential loops for bootstrap simulations with 2D vectorized NumPy operations, and compute simple linear regression metrics like $R^2$ algebraically over matrices instead of using iterative polyfit functions.
