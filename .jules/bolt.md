## 2025-02-14 - Optimize ML Ensemble Training & Validation
**Learning:** ML pipeline training is a massive bottleneck in Streamlit applications because Streamlit re-runs the entire script on tab or UI parameter changes. We can optimize cross-validation folds and tree estimators to balanced levels (e.g., cv=3, estimators=100/80) without breaking correctness or reliability metrics, cutting pipeline execution time by ~50%. Furthermore, using `feature_vector.tobytes()` as a cache key in a bounded `OrderedDict` (size 16) avoids memory leaks in long-running apps, and storing/restoring fitted model state variables during cache hits preserves instance state correctness.
**Action:** Always implement bounded cache eviction policies and fully restore fitted model attributes on cache hits to avoid memory leaks and instance-bypassing bugs in cached ML predictors.
