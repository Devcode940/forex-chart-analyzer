## 2026-08-09 - ML Cache and Hyperparameter Tuning
**Learning:** Streamlit applications are highly sensitive to full-script re-execution, causing expensive ML pipelines (such as `MLEnsemble` and `WalkForwardValidator`) to run repeatedly on every UI tab switch or interaction. Utilizing input-hash-based cache keys (e.g. `feature_vector.tobytes()`) in a bounded OrderedDict cache (capacity 16) bypasses redundant training and inference overhead. Tuning model hyperparameters (RF estimators 100, GB estimators 80/50, and CV folds 3) significantly reduces individual model training and cross-validation fitting time while maintaining production-ready accuracy.
**Action:** Always implement input-hash-based bounded stateful caching on computationally heavy ML/statistical modules to avoid redundant calculations on UI/tab changes, and balance estimator sizes for quick model convergence.
