## 2025-05-18 - ML Ensemble Training & Cross-Validation Optimization
**Learning:** `MLEnsemble.train_and_predict` was taking ~38.4 seconds per call due to sequential 5-fold cross-validation on RandomForestClassifier and GradientBoostingClassifier, alongside unoptimized estimator counts. Caching ML predictions requires serializing all context arguments (`feature_vector`, `pattern_results`, `structure_results`, `regime_results`, `confluence_results`) and restoring instance attributes (`rf_model`, `gb_model`, `meta_model`, `scaler`, `is_trained`, `training_stats`) on cache hits.
**Action:** Use 3-fold cross-validation with `n_jobs=-1` on RandomForestClassifier and balanced estimator counts (100 RF / 80 GB). Wrap prediction runs with a bounded OrderedDict cache using full context hashing to safely bypass model re-fitting on UI/tab changes.
